# UrbanResilience — Demand & Origin-Destination (OD) Model

## 1. Objective & Main Question

> **Where does urban traffic originate, where is it destined, and how does demand fluctuate across peak periods?**

Traffic is not an intrinsic property of road asphalt; it is the physical manifestation of human activities distributed across space. The **Demand Model** defines how commuter, commercial, and emergency trip flows are generated, distributed between spatial zones, and converted into link-level vehicle volumes.

---

## 2. Origin-Destination (OD) Matrix Schema

Vehicular demand is represented as a collection of typed `ODDemand` records:

```python
@dataclass(frozen=True)
class ODDemand:
    id: str                   # Unique trip demand identifier
    origin: str               # Source Traffic Analysis Zone (TAZ) node ID
    destination: str          # Target destination TAZ node ID
    demand_veh_per_hour: float # Vehicular flow rate during analysis period
    time_period: str = "peak" # "morning_peak", "evening_peak", "off_peak"
    vehicle_class: str = "car"# "car", "2W", "3W", "bus", "commercial"
```

---

## 3. Trip Generation & Land-Use Attribution

In macroscopic transport modeling, zone-to-zone demand $T_{ij}$ from origin zone $i$ to destination zone $j$ is governed by a Gravity Model formulation:

$$T_{ij} = K \\cdot \\frac{P_i^{\\alpha} \\cdot A_j^{\\beta}}{f(c_{ij})}$$

where:
- **$P_i$ (Trip Production)**: Number of trips generated by origin zone $i$ (proportional to residential population and housing density).
- **$A_j$ (Trip Attraction)**: Number of trips attracted to destination zone $j$ (proportional to commercial office square footage, retail centers, and hospital beds).
- **$c_{ij}$**: Generalized travel cost (free-flow travel time or distance) between zone $i$ and zone $j$.
- **$f(c_{ij}) = c_{ij}^\\gamma$**: Distance-decay friction function.

---

## 4. Peak-Hour Demand Scaling

Because traffic datasets (such as `Banglore_traffic_Dataset.csv`) frequently record daily aggregate volumes, the simulation converts 24-hour totals into design peak-hour flow rates using standard empirical factors:

$$V_{\\text{peak}} = V_{\\text{daily}} \\cdot k_{\\text{peak}}$$

- **$k_{\\text{peak}}$ (Peak Hour Factor)**: Standard transportation planning value range: $k_{\\text{peak}} \\approx 0.08 - 0.10$ ($8\\% - 10\\%$ of daily traffic occurs in the morning peak hour, typically 08:30–09:30 AM).
- **Example**: A corridor with $30,000\\text{ veh/day}$ exhibits an estimated peak flow of $V_{\\text{peak}} = 30000 \\times 0.085 = 2,550\\text{ veh/h}$.
